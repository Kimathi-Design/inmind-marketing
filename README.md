# Inmind marketing

Public marketing / landing site for [Inmind](https://inmind.media).

## Local

```bash
pnpm install
pnpm dev
```

Runs on [http://localhost:3001](http://localhost:3001).

## Build

```bash
pnpm build
```

## Deploy

Connected to Vercel from this repo. Set `NEXT_PUBLIC_SITE_URL` to the production host.
